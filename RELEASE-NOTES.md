# 0.1.1 public preview

Standalone Mischief package for MagicMirror² 2.38.0 or newer with manual installation, a complete settings reference, examples, Mirror Mischief companion guidance, attribution and rendered previews.

Automated package/model/failure-path checks and isolated browser rendering were run locally. Provider/health/economy screenshot values are explicitly synthetic. Independent physical-mirror installation remains to be verified. One instance per module is supported.

The companion is optional and its public installer is not yet released. See MIRROR-MISCHIEF.md and VALIDATION.md. Preserve private settings and local customizations before upgrading an existing folder.

Timezone-boundary regression tests now use explicit zones; UTC and America/Los_Angeles boundaries are both checked.
