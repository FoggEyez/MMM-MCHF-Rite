# Rite troubleshooting

- A selected scene is a preview. Calendar mode can show a different holiday scene; the status above the preview explains the current display rule.
- Use selected scene switches to manual mode. Save to mirror, or export and apply config.js, to change the display.
- If an accent is missing, check the target selector, its occurrence index, and clear areas. Full-screen layers stay transparent.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
